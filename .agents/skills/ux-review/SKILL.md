# ux-review

## Steps
1. Read `SPEC.md` (Who, When, Where, How) and the app's files.
2. Imagine the user from SPEC.md in their situation (e.g. Mom in a shop, one hand, on a phone). Walk through: open the app, add a task, tick it, find what is left, delete one, reload.
3. Write at most 3 tips, most important first. Each tip:
   - `Tip <n>: <the change>`
   - `Why for <Who>: <one line tied to a SPEC.md line>`
   - `Standard: <the rule it follows>` (tap size 44px, contrast 4.5:1, clear empty state, Enter adds a task, focus visible, no sideways scroll at 360px)
4. Then ask: "For each tip, write yes or no, and why in a few words."
5. Change nothing before the learner answers. Apply only the tips they said yes to. Do not save (commit): end with "Check in Chrome: …" and "Looks right? Type: Save this version." (AGENTS.md rule 4).
6. If a tip the learner rejects breaks a standard, say so once, kindly, and respect their choice.
